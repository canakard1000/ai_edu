# 첫알바톡

첫 아르바이트를 시작하는 사용자를 위한 근무 기록, 급여 참고 계산, 첫 출근 준비, 도움 링크, 라운지, 내정보 기능을 담은 모바일 우선 미니앱입니다.

## 실행

```bash
npm install
npm run dev
```

## 스크립트

- `npm run lint`
- `npm run test`
- `npm run typecheck`
- `npm run build`

## 메모

- 운영용 광고 ID는 `.env`로만 주입합니다.
- 공식 기관 링크만 사용합니다.
- 모든 법률/급여 안내는 참고 정보로만 표시합니다.
